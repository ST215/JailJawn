# Contributors

JailJawn began at a civic hackathon with the City of Philadelphia in 2013 and grew across several repositories in the JailJawn GitHub organization before being brought together here. Everyone who pushed a commit, opened a pull request, or filed an issue on any of them is listed. Unmerged work counts: it shaped what was merged.

## Scraper

- **Stanley Griggs II** ([@ST215](https://github.com/ST215)) — created the project, wrote the original scraper, the Lambda and Firebase pipeline, and every version since.
- **Maurice Jenkins** ([@mauricej9](https://github.com/mauricej9)) — Unicode handling in the original scraper and the first README rewrite (pull requests #13, #15, #16, #17 on the scraper, 2015).

## Web app (jailjawnapp) and API (JailJawnAPI)

- **Kevin Diem** ([@kgdiem](https://github.com/kgdiem)) — built the Node API and most of the web app; filed the issue that documented the column shift in the Firebase data, which this repository's legacy import corrects.
- **[@skyehorbrook](https://github.com/skyehorbrook)** — web app front end.
- **Lauren Ancona** ([@laurenancona](https://github.com/laurenancona)) — styles and Open Graph tags for the web app (pull requests #5 and #7 merged, #6 closed).
- **simon** ([@selichko](https://github.com/selichko)) — pointed out that earlier census data was available (issue #8), which is why the 2013–2017 chapter exists.
