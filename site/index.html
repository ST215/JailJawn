The data

Since March 2025: one CSV with a row per day and a JSON file per day with the five tables as the city published them, committed to a public repository the morning each is captured. From 2013 to 2017: the first scraper's record, cleaned and documented.

census.csv · 2013–2017 summary.csv · Schema · Daily JSON · Data package · llms.txt

Query the daily record in your browser with Datasette Lite, no install needed.

The data is public domain (CC0): it is what the city published, collected here, offered as is with no warranty. Do anything with it. A mention of JailJawn by Stanley Griggs II is appreciated, not required. The code is MIT. If you are a person or a program building on this, llms.txt and the data package describe every file, and CITATION.cff gives a citation.

Source

The Philadelphia Department of Prisons daily census page, collected with the city's permission. The city posts one day at a time and does not include this data in its open data portal.

Method

A scheduled job opens the page in a headless browser twice a day, parses the five tables, checks the arithmetic and the date, and commits the result. Nothing is stored unless it passes. Code and history on GitHub.

Built with

The crowd is laid out with pretext by Cheng Lou and drawn with Material Symbols. No framework, no build step. Data public domain (CC0), code MIT, no warranties. A non-profit civic project by Stanley Griggs II.
