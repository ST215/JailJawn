The data

One CSV, one row per census day, 164 columns. One JSON file per day with the five tables as the city published them. Every file is committed to a public repository the morning it is captured.

The latest census as a table

Source

The Philadelphia Department of Prisons daily census page, collected with the city's permission. The city posts one day at a time and does not include this data in its open data portal.

Method

A scheduled job opens the page in a headless browser twice a day, parses the five tables, checks the arithmetic and the date, and commits the result. Nothing is stored unless it passes. Code and history on GitHub.

About

Started as a civic hackathon project and a way to learn Python. Built and maintained by Stanley Griggs. The crowd on this page is laid out with pretext.
